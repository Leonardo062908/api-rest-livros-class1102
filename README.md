# API RESTful de Livros 📚
Este é um projeto de API RESTful desenvolvido com **Spring Boot** para gerenciar livros. Ele inclui operações **CRUD** (Create, Read, Update, Delete).

## 🚀 Tecnologias Utilizadas
- Java 21
- Spring Boot
- Spring Data JPA
- H2 Database (Banco em Memória)
- Gradle

## 📌 Funcionalidades
- 📌 Criar um novo livro (POST `/livros`)
- 🔍 Listar todos os livros (GET `/livros`)
- 📖 Buscar um livro por ID (GET `/livros/{id}`)
- ✏️ Atualizar um livro (PUT `/livros/{id}`)
- 🗑 Deletar um livro (DELETE `/livros/{id}`)
